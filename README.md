# LAB4

Aceasta este varianta usor de rulat local, cu bridge PHP catre scripturile Python.

## Cum rulezi

Din radacina proiectului:

```bash
./LAB4/start-lab4.sh
```

Deschizi in browser:

```text
http://127.0.0.1:8000/LAB4/index.html
```

## Ce este functional

- autentificare
- inregistrare cont
- trimitere cerere de oferta
- salvare profil firma
- raportare problema locala

## Unde ajung datele

Datele sunt salvate in:

```text
LAB4/data/
```
