# LAB5

Aceasta este varianta pentru laboratorul AJAX. Formularele nu mai fac submit clasic, ci trimit datele asincron catre endpoint-uri PHP care raspund in format JSON.

## Cum rulezi

Din radacina proiectului:

```bash
./LAB5/start-lab5.sh
```

Deschizi in browser:

```text
http://127.0.0.1:8000/LAB5/index.html
```

## Ce este functional

- autentificare AJAX
- inregistrare cont AJAX
- trimitere cerere de oferta AJAX
- salvare profil firma AJAX
- raportare problema locala AJAX
- panou dinamic care incarca datele salvate prin `fetch()`

## Unde ajung datele

Datele sunt salvate in:

```text
LAB5/data/
```
